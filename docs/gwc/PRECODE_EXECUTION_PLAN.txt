GLOBAL CONTRACT PROCEDURE
Every GW contract is executed conceptually through the same nine stages:
1. ENTER — load only the bounded input selected by the canonical workflow graph.
2. OBSERVE — observe the owning authority before deriving or acting.
3. VALIDATE — validate schema, identity/binding, freshness, contradictions and preconditions; UNKNOWN remains UNKNOWN.
4. DERIVE — derive only facts owned by this contract; never infer facts owned by another authority.
5. AUTHORIZE_IF_MUTATING — require callable && authorized && safeNow && preconditionsSatisfied, plus current task/session/receipt/locks where applicable.
6. ACT_OR_RECORD — execute only action kinds explicitly allowed by the contract.
7. VERIFY — re-observe postconditions from owning authorities; invocation success is never proof.
8. ATTEST — record only bounded evidence refs/reason codes/freshness; never secrets/raw credentials/arbitrary prompt bodies.
9. ROUTE — route only through .mcp/gwc-workflow-graph.json; numeric GW order is never authority.

FAIL-CLOSED ROUTING
STALE -> reobserve owning authority and invalidate dependent evidence.
CONFLICT -> reconcile current Task Queue/session/lock/GitHub state; never force.
AMBIGUOUS -> block until the owning resolver disambiguates; no heuristic candidate choice.
UNVERIFIED -> no mutation; obtain authoritative evidence or remain blocked.
BLOCKED -> preserve reason and continue only independent work whose dependencies/scopes allow it.
REJECTED -> terminate this route with explicit reason; never downgrade to warning.

GLOBAL INVARIANTS
INTENT != AUTHORIZATION.
CALLABLE != AUTHORIZED != SAFE_NOW.
UNKNOWN never permits mutation.
GitHub fact != runtime fact.
Blueprint != GovernedTaskRecord.
Branch-local candidate work items are not runtime Tasks. Only the later real-integration phase may use the live Governed Task Queue, and then only according to the current runtime governance observed at that time.
Observe before act.
Exact head before merge.
Exact SHA before runtime truth.
No false DONE.
No parallel Live State, Task Queue, Session, Lock, GitRegistry, Operational Memory, GitHub control plane or deployment authority.
