## Distinction code / livraison / autorisation

Le parcours de la PR #355 a accumulé des implémentations et tests (E3/OAuth, Task/Session/Lock, Plesk). Les preuves de **permissions administratives effectivement attestées**, de **création réelle via Plesk**, de **HTTPS**, d'une **application déployée** et du **rollback réel** restent distinctes. Ne pas revendiquer un déploiement depuis un test mock ni lever `PLESK_WRITE_HOLD` sur la seule base d'un consentement fonctionnel.

**Source de statut vivant** : HEAD actuel et derniers checkpoints de [#349](https://github.com/Patricked-code/MCP/issues/349) et [#355](https://github.com/Patricked-code/MCP/pull/355), puis vérification de S1/S2. Les liens ci-dessus sont des *preuves historiques*, pas la permission de muter.
