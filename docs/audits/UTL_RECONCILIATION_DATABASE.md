# UTL reconciliation database

An offline SQLite read model has been created for historical evidence reconciliation. It contains mandate, UTL, task circuit, continuity, PR, commits, workflow, deployment, runtime and reconciliation entities. It is not a replacement for MCP runtime authorities. Missing historical evidence remains explicitly unverified.

Live baseline as of 2026-11-03: main/runtime `05dbb66ed81aa4e7443655c89d10c0c390ff0f10`, state 1202. Historical completeness has not been established.
