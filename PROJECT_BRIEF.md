# PROJECT_BRIEF.md

## Role
Brief strategique du MCP WealthTech.

## Projet
Le MCP WealthTech SSH Bridge sert de couche d'acces controle, de memoire operationnelle et de gouvernance entre ChatGPT, Claude Code, Codex, GitHub et les serveurs.

## Objectif
Eviter la perte de contexte, le codage a l'aveugle, les regressions et les confusions entre serveurs, depots, branches, domaines et agents.

## Intentions du projet MCP

Le mandat stratégique ci-dessus est complété par les intentions documentées dans les [instructions fondatrices de Loop Engineering](memory/LOOP_ENGINEERING_INSTRUCTIONS_DOCX_EXTRACT_20260702.md) et les [décisions du projet](DECISIONS_LOG.md). Les intentions explicitement confirmées pour la [mission #441](https://github.com/Patricked-code/MCP/issues/441) sont :

- Ne jamais perdre la continuité entre agents, modes d'entrée et niveaux hiérarchiques ; réutiliser les autorités existantes sans registre concurrent.
- Appliquer un [plan documentaire commun à tous les modes d'entrée](https://github.com/Patricked-code/MCP/issues/441#issuecomment-7121508184), maintenir tous les documents concernés et conserver la preuve d'actualité des autres ; préserver l'historique.
- Restituer le rôle de SUIVI, Loopback et Loop Engineering : lecture avant travail, mémoire, plan, preuves, réconciliation, prochaine action et reprise vérifiée.
- Détecter, expliquer, corriger et réattester les différences documentaires après chaque Governed Deploy ; ne jamais déclarer conformes les sources non vérifiées.

Ces intentions ne remplacent pas les mandats des chantiers ni les permissions opérationnelles. Les sources conversationnelles non disponibles, les exigences non encore qualifiées et la couverture complète restent à vérifier. L'identifiant documentaire du projet ne crée aucun ProjectRecord runtime.
